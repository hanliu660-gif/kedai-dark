# 夜间模式截图（验证留档）

`夜间模式：QQ 中性配色` 那一批改动（提交 `9dd4585`）的**验收证据**。

## 为什么放在仓库里

原先这些图放在 `dist/夜间模式截图/`，而 `dist/` 是构建产物目录（`.gitignore:3`），
`build.ps1` 会整个刷新它 —— 也就是说**跑一次构建证据就没了**。归档到 `docs/fixtures/`
才与 `tools/check-docs.mjs` 的目录白名单兼容（`docs/` 根下只认六类活文档 + `docs/fixtures/`）。

## 采集条件

- 桌面 Web（`web/`，Vite 开发服务器），Chromium 内核
- 窗口 1600×1000，界面缩放 100%
- 同一份 `dist/kedai-server.exe` 分别用「深色 / 浅色」两档主题各采一遍
- 采集时间 2026-10-19 08:44 ～ 18:28
